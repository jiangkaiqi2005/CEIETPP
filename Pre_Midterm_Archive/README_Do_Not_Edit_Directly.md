# 中期答辩前资料归档说明

这个目录用于原样保留中期答辩前的资料，不建议在这里继续改数据、改训练脚本或覆盖权重。

当前主要内容：

- `Pre_Midterm_Workflow.md`：中期答辩前 YOLO 训练流程总结。
- `main`：历史主目录，包含数据、转换脚本、早期 YOLOv8 相关文件。
- `finish-data`：历史整理后的数据副本。
- `yolo-cocostuff`：公开数据或 COCO 风格预训练相关资料。
- `runs`：历史训练输出和权重。

后续如果要复用这里的内容，建议复制到 `Post_Midterm_Workspace` 中对应目录，再在新目录里修改。

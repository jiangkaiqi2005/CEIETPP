# 实验室电脑关键信息

这个目录记录历史上疑似在实验室电脑完成的训练工作。

## 历史推断

实验室电脑更像承担了“训练”的工作，依据是：

- 历史训练输出中多次出现 `D:\CEIETPP\yolo-cocostuff\runs\segment\...`。
- 早期 YOLOv8 线索中出现 `C:\Users\Administrator\Desktop\yolov8`。
- 早期 YOLOv8 训练输出路径出现 `E:\Yolo\YoloStudy\src\yolov8`。
- 训练参数均使用 `device: 0`，说明当时使用了 GPU。

这个推断需要以后在实验室电脑上核对真实路径、显卡和环境版本。
